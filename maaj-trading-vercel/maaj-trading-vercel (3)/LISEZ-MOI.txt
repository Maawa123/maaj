MAAJ TRADING – SITE STATIQUE POUR VERCEL

MISE EN LIGNE
1. Compte gratuit sur https://vercel.com (connexion avec GitHub).
2. Créez un dépôt GitHub (ex. "maaj-site"), puis "Add file > Upload files" :
   glissez TOUT le contenu de ce dossier.
3. Vercel : "Add New > Project" > importez le dépôt > Framework : "Other" > Deploy.
4. Domaine : Settings > Domains > maajtrading.com, puis recopiez les DNS
   (A / CNAME) chez votre registrar. Ne touchez pas aux MX (emails).

MODIFIER UN TEXTE
GitHub > fichier .html > crayon > modifier > Commit. Vercel republie seul.

IMAGES ET CATALOGUES
Vos images sont dans /images, les catalogues PDF (EN et FR) à la racine.
Pour remplacer une image, gardez le même nom de fichier.

IMAGES À REMPLACER (déposez-les dans /images avec EXACTEMENT ces noms)

LANGUES
Le site existe en 3 langues :
- anglais  : maajtrading.com/
- français : maajtrading.com/fr/
- arabe    : maajtrading.com/ar/   (lecture de droite à gauche)
Le sélecteur EN | FR | ع en haut à droite renvoie vers la même page dans l'autre langue.
Les pages légales (mentions, confidentialité, cookies) restent rédigées en français dans les 3 versions.
Pour modifier un texte français : dossier fr/ ; arabe : dossier ar/.
